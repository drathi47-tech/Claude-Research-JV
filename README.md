# Consumer Trend Radar — Jungle Ventures

A multi-platform consumer trend analysis dashboard for identifying breakout D2C and consumer brands across India.

## How to Use

1. Open `index.html` in any modern browser (Chrome, Firefox, Safari, Edge)
2. No build step, no dependencies to install — it works out of the box

## Dashboard Sections

| Section | What it shows |
|---------|---------------|
| **Overview** | Cross-platform heatmap, composite scores, top movers table |
| **Google Trends** | Search interest over time, regional breakdown, rising queries |
| **Amazon / Myntra** | Review volume & velocity, rating trends, sentiment analysis, keyword cloud |
| **Website Traffic** | Monthly visit estimates, traffic source breakdown, engagement metrics |
| **Reddit / Instagram** | Mention volume, social sentiment, trending posts, viral score |
| **Breakout Detector** | Companies showing simultaneous signals across 3+ platforms |
| **Watchlist** | Curated company cards with composite scores at a glance |

## Features

- **Platform Toggles**: Switch between Amazon/Myntra and Reddit/Instagram views
- **Sector Filtering**: Filter by Beauty, Food, Fashion, Health, Home, Electronics
- **Time Range**: 7d / 30d / 90d / 6m / 1y views
- **Search**: Real-time search across all tables
- **Add Company**: Add new companies to track with platform selection
- **Breakout Detection**: Automated multi-signal scoring to flag companies gaining traction across platforms
